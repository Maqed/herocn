`Trace` is a list of rows for the steps an agent takes, like calling a tool, running a command, or reading a file. Every row has the same shape, so reasoning, tool calls, sources, and plans look and behave the same.

Use `Trace` for the steps an agent takes. Use [`Message`](/docs/components/message) for its reply, and [`Marker`](/docs/components/marker) for notes and dividers between turns.

## Usage

```tsx
import { Trace, TraceIcon, TraceLine, TraceTitle } from "@/components/ui/trace"
```

```tsx
<Trace>
  <TraceLine>
    <TraceIcon>
      <SearchIcon />
    </TraceIcon>
    <TraceTitle>Searched for minimumReleaseAge</TraceTitle>
  </TraceLine>
</Trace>
```

Wrap the row in a `TraceCollapsible` to show more detail when it expands:

```tsx
import {
  Trace,
  TraceCollapsible,
  TraceCollapsibleContent,
  TraceCollapsibleTrigger,
  TraceIcon,
  TraceLine,
  TraceTitle,
} from "@/components/ui/trace"
```

```tsx
<Trace>
  <TraceCollapsible>
    <TraceCollapsibleTrigger>
      <TraceLine>
        <TraceIcon>
          <TerminalIcon />
        </TraceIcon>
        <TraceTitle>Ran node --version</TraceTitle>
      </TraceLine>
    </TraceCollapsibleTrigger>
    <TraceCollapsibleContent>v24.18.0</TraceCollapsibleContent>
  </TraceCollapsible>
</Trace>
```

## Composition

Use the following composition to build a trace row:

```text
Trace
└── TraceLine
    ├── TraceIcon
    ├── TraceTitle
    ├── TraceDescription
    └── TraceIcon
```

Wrap the row in a `TraceCollapsible` to show more detail when it expands:

```text
Trace
└── TraceCollapsible
    ├── TraceCollapsibleTrigger
    │   └── TraceLine
    └── TraceCollapsibleContent
```

`TraceLine` is always the row. To make a row do something, wrap it in that thing's trigger, such as a link or a `TraceCollapsibleTrigger`.

### Trace Line

### Status

Set `status` on `TraceLine` when a step is running, has failed, or hasn't started yet. Write the title to match the status: present tense while running ("Running pnpm build") and past tense when done ("Ran pnpm install").

<ComponentPreview name="trace-status" />

| Status    | Use for                                                       |
| --------- | ------------------------------------------------------------- |
| none      | Work that is done: "Ran pnpm install".                        |
| `"error"` | Work that failed. Say so in the title: "Failed to run pnpm lint". |
| `"running"` | Work in progress. Write the title in the present tense: "Running pnpm build". |
| `"pending"` | Work that has not started, such as a plan step: "Run pnpm test". |

### Open State

Rows start closed. Use `defaultOpen` on `TraceCollapsible` to start open, or `open` with `onOpenChange` to control a row.

<ComponentPreview name="trace-open" />

To open a row while it streams and let the reader's click win, pass `open ?? running`.

```tsx showLineNumbers
const [open, setOpen] = React.useState<boolean>()

<TraceCollapsible
  open={open ?? running}
  onOpenChange={setOpen}
>
  <TraceCollapsibleTrigger>
    <TraceLine status={running ? "running" : undefined}>…</TraceLine>
  </TraceCollapsibleTrigger>
  <TraceCollapsibleContent>{text}</TraceCollapsibleContent>
</TraceCollapsible>
```

### Link

Wrap the `TraceLine` in an anchor to make the row navigate. For a link that opens a new tab, use an arrow-up-right icon and add "(opens in a new tab)" to the title with `sr-only`.

## Accessibility

`Trace` adds no roles of its own. Each row gets its semantics from the element that wraps it.

- A `TraceLine` on its own is a `span`. It is read as text and is not a tab stop.
- Wrap it in a `TraceCollapsibleTrigger` and it becomes a button with `aria-expanded`. Wrap it in a link and it takes the keyboard and focus behavior of that element.
- `TraceIcon` is hidden from assistive tech, so `TraceTitle` is the accessible name. Write it as a sentence that says what happened, like "Edited trace.tsx", not just "trace.tsx".
- When a link opens a new tab, add "(opens in a new tab)" to the title with `sr-only`.
- Status is shown with color and motion, so put it in the title too. Write "Running pnpm build" while it runs and "Failed to run pnpm build" when it errors.
